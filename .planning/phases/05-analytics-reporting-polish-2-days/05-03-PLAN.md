<task type="auto">
  <name>Task 1: Create LoadingSkeletons component library</name>
  <files>src/app/components/admin/LoadingSkeletons.tsx</files>
  <action>
Create reusable skeleton components for loading states.

**Exports:**

1. **SkeletonChart({ height = 300 })**
   - Div with h-{height}, bg-slate-800/40, rounded-lg, animate-pulse
   - No content, purely visual placeholder
   - Used by RevenueTrendChart, DistributionBreakdownChart while fetching

2. **SkeletonCard()**
   - Div with h-24 (KPI card height), bg-slate-800/40, rounded-lg, animate-pulse
   - Used by AnalyticsCards (show 4 skeletons while loading)

3. **SkeletonTable({ rows = 5 })**
   - Container with space-y-2
   - {rows} divs each with h-12, bg-slate-800/40, rounded, animate-pulse
   - Used by AuditLogViewer, UserManagementTable while fetching

4. **SkeletonForm()**
   - Form-shaped skeleton:
     - h-10 input skeleton (x2, stacked)
     - h-40 textarea skeleton
     - h-10 button skeleton
   - Used by DistributionForm while calculating

**Styling Pattern:**
- All use: bg-slate-800/40 (dark overlay), rounded-lg
- Height varies per component type
- animate-pulse from Tailwind (opacity fade)
- No borders (simpler than data)
- Margins match adjacent elements

**Code Example:**
```tsx
export const SkeletonChart = ({ height = 300 }: { height?: number }) => (
  <div 
    className={`h-${height} bg-slate-800/40 rounded-lg animate-pulse`}
  />
);

export const SkeletonCard = () => (
  <div className="h-24 bg-slate-800/40 rounded-lg animate-pulse" />
);

export const SkeletonTable = ({ rows = 5 }: { rows?: number }) => (
  <div className="space-y-2">
    {[...Array(rows)].map((_, i) => (
      <div key={i} className="h-12 bg-slate-800/40 rounded animate-pulse" />
    ))}
  </div>
);

export const SkeletonForm = () => (
  <div className="space-y-4">
    <div className="h-10 bg-slate-800/40 rounded animate-pulse" />
    <div className="h-10 bg-slate-800/40 rounded animate-pulse" />
    <div className="h-40 bg-slate-800/40 rounded animate-pulse" />
    <div className="h-10 bg-slate-800/40 rounded animate-pulse" />
  </div>
);
```

**Usage in Components:**
- RevenueTrendChart: `{isLoading ? <SkeletonChart /> : <LineChart />}`
- AnalyticsCards: `{isLoading ? [...Array(4)].map(() => <SkeletonCard />) : <Cards />}`
- AuditLogViewer: `{isLoading ? <SkeletonTable /> : <Table />}`

**No TypeScript issues** - simple component functions with optional props

**Changes to tailwind.config.js:**

```js
  theme: {
    extend: {
      // ... existing extends ...
      animation: {
        fadeIn: 'fadeIn 0.5s ease-in-out',
      },
      keyframes: {
        fadeIn: {
          '0%': { opacity: '0' },
          '100%': { opacity: '1' },
        },
      },
    },
  },
  // ... rest of config ...
};
```

**Usage in Components:**
- Wrap chart containers: `<div className="animate-fadeIn">`
- Wrap data tables: `<div className="animate-fadeIn">`
- When data loads, fade in from opacity 0 to 1 over 0.5s

**Alternative: Skip Tailwind Config**
If animate-fadeIn not needed, can use inline styles:
```tsx
<div style={{ animation: 'fadeIn 0.5s ease-in-out' }}>
```

But Tailwind approach is cleaner and reusable.

**No breaking changes** - only adds new animation utility
