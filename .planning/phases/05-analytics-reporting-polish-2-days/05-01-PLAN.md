<task type="auto">
  <name>Task 4: Create analyticsUtils.ts data layer</name>
  <files>src/app/lib/analyticsUtils.ts</files>
  <action>
Create utility functions for analytics data fetching from Supabase.

**Exports:**
1. `fetchRevenueByDate(days = 7)`: Returns array [{date, revenue}] for last N days
   - Query: SELECT DATE(created_at) as date, SUM(amount) as revenue FROM distributions WHERE created_at >= NOW() - INTERVAL '{days} days' GROUP BY DATE(created_at) ORDER BY date ASC
   - Error handling: Returns last 7 days of dummy data (0-5 ETH random) on RPC failure
   - Type: Promise<{date: string, revenue: number}[]>

2. `fetchDistributionByRecipient(limit = 10)`: Returns top N recipients by total amount
   - Query: SELECT r.id, r.recipient_id, u.name, SUM(r.amount) as total FROM distribution_recipients r JOIN users u ON r.recipient_id = u.id GROUP BY r.recipient_id, u.name ORDER BY total DESC LIMIT {limit}
   - Type: Promise<{recipient_id: string, name: string, total: number}[]>
   - Error handling: Returns empty array if fails

3. `aggregateMetrics()`: Returns {totalDistributed, pending, failed, successRate}
   - Query 1: SELECT SUM(amount) as total FROM distributions WHERE status='confirmed'
   - Query 2: SELECT COUNT(*) as count FROM distributions WHERE status='pending'
   - Query 3: SELECT COUNT(*) as count FROM distributions WHERE status='failed'
   - Query 4: SELECT COUNT(CASE WHEN status='confirmed' THEN 1 END) as confirmed, COUNT(*) as total FROM distributions
   - successRate = confirmed / total * 100
   - Type: Promise<{totalDistributed: number, pending: number, failed: number, successRate: number}>
   - Error handling: Return all zeros if fails

4. `formatEthValue(wei: string | number)`: Returns formatted ETH string
   - Use ethers.formatEther(wei)
   - Round to 6 decimals for display
   - Add commas for thousands (2.5 ETH vs 2,500.123 ETH)

**Error Handling:** All functions should log errors to console but not throw (return defaults)

**Dependencies:** Use existing supabaseClient from src/app/lib/supabaseClient.ts
