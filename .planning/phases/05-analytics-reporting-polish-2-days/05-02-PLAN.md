<task type="auto">
  <name>Task 2: Create reportUtils.ts with CSV and PDF generators</name>
  <files>src/app/lib/reportUtils.ts</files>
  <action>
Create utility functions for report generation.

**Exports:**

1. **exportTransactionsCSV(transactions: Transaction[], fromDate: Date, toDate: Date)**
   - Input: Array of transactions, date range
   - CSV format: Header row + data rows
   - Headers: "Date", "Recipient", "Amount (ETH)", "Status", "Transaction Hash"
   - Data rows: For each tx, format date as YYYY-MM-DD, amount with 6 decimals, status as-is
   - Filename: `transactions-${dateRange}.csv` (e.g., `transactions-2026-04-01-to-2026-04-13.csv`)
   - Implementation:
     ```ts
     const headers = ['Date', 'Recipient', 'Amount (ETH)', 'Status', 'Transaction Hash'];
     const rows = transactions.map(tx => [
       new Date(tx.created_at).toISOString().split('T')[0],
       tx.recipient_name || tx.recipient_id.slice(0, 8),
       formatEthValue(tx.amount),
       tx.status,
       tx.tx_hash || 'N/A'
     ]);
     const csvContent = [
       headers.join(','),
       ...rows.map(row => row.map(cell => `"${cell}"`).join(','))
     ].join('\n');
     
     const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8;' });
     const link = document.createElement('a');
     link.href = URL.createObjectURL(blob);
     link.download = `transactions-${dateRange}.csv`;
     link.click();
     ```
   - Error handling: If array empty, still export headers (shows 0 records)

2. **exportDistributionPDF(distributions: Distribution[], fromDate: Date, toDate: Date)**
   - Input: Array of distributions, date range
   - PDF structure:
     ```
     [LOGO/HEADER]
     Distribution Report
     Date Range: April 1, 2026 - April 13, 2026
     
     Summary:
     - Total Amount: 12.5 ETH
     - Number of Recipients: 8
     - Distributions: 3
     
     Recipient Breakdown:
     [TABLE: Recipient Name | Amount | % of Total]
     
     [Generated: April 13, 2026 at 14:30 UTC]
     ```
   - Use jsPDF + html2canvas:
     1. Render PDF content to hidden div (off-screen)
     2. Use html2canvas to convert div to PNG image
     3. Insert image into PDF
     4. Download PDF
   - Filename: `distribution-report-${dateRange}.pdf`
   - Error handling: If generation fails, show toast "PDF export failed"

3. **formatEthValue(wei: string | number): string**
   - Use ethers.formatEther() to convert to ETH
   - Round to 6 decimals
   - Return as string with ETH suffix

4. **formatDateRange(fromDate: Date, toDate: Date): string**
   - Return "YYYY-MM-DD-to-YYYY-MM-DD" format for filenames
   - E.g., "2026-04-01-to-2026-04-13"

**Dependencies:**
- import jsPDF from 'jspdf'
- import html2canvas from 'html2canvas'
- import { formatEther } from 'ethers'
- import toast from 'react-hot-toast'

**Error Handling:**
- Wrap all exports in try-catch
- Show toast error on failure: "Failed to export {format}: {error}"
- Log error to console for debugging
