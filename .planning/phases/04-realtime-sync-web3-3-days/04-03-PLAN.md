  <name>Task 3: Create balanceReconciliation.ts utility</name>
  <files>src/app/lib/balanceReconciliation.ts</files>
  <action>
Create utility functions for balance reconciliation:

1. reconcileBalance(): Promise<{
     contractBalance: bigint;
     dbBalance: bigint;
     discrepancy: bigint;
     isReconciled: boolean;
     action: string;
   }>
   - Fetch current contract balance: contract.getContractBalance()
   - Fetch DB balance: SUM(amount) FROM distribution_recipients
   - Compare: if abs(discrepancy) > tolerance (1e15 wei = 0.001 ETH), flag as unreconciled
   - If discrepancy found, log to activity table: action='balance_discrepancy', details={contract, db}
   - Return all values for inspection

2. formatBalance(wei: bigint): string
   - Convert wei to ETH with 4 decimal places
   - Used for logging/display

3. getBalance tolerance(): bigint
   - Return 1e15 (0.001 ETH) tolerance
   - Accounts for minor rounding differences

  </action>
